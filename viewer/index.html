      Reading the map

      The project is a globe with a grid of 100 rows and 100 columns. Every folder, file and piece of code is a tiny speck of dust, scattered over the globe. Each folder sits in the middle of its files and subfolders, in rings, and each file is surrounded by its code.

      dust colours
      Folders are off-white; files and their code are coloured by language, in pastels (the key is at the top left of the map). Folders and files are a little bigger than code. Dust on the far side of the globe is dimmer.
      panel
      The panel button at the top right (or /) shows or hides the panel on the right: search, the folders, the numbers (how many folders, files and pieces of code there are, and links) and the health checks. It's hidden at first. In the numbers, click a kind (functions, classes, html ids…) to light up those items and whatever declares or uses them; click it again to clear.
      folders
      The panel lists the folders under the search box, closed at first: click one to see the files inside it. Clicking a folder or file glides the globe round until it faces you.
      names
      Pointing at a speck rings it and shows what it is: its name, language, and how many files, code parts or links it has. The selected speck and a few of its neighbours are named on the globe.
      links
      Links aren't drawn. Click a speck and what it's linked to lights up; click a language in the colour key (or a kind in the numbers panel) to see where it's used. Click it again or press Esc to clear.
      web
      The web switch at the top (or V) shows the folders and files as a flat web instead: lines join each folder to what's inside it and each file to the files it loads, imports, calls or uses, and better-linked specks are a little bigger. It's all fine dust, and each file's code parts float round it in a little cloud. It settles by itself, then stays still. Drag empty space to move around, drag a dot to pull it (the rest follow).
      spin
      The globe turns slowly on its own axis (once in about 10½ minutes) and Claude's core inside it turns slowly the other way. The spin button at the top (or S) stops and starts both; it starts off when your computer asks for less motion.
      Claude's core
      On the map of all your projects, Claude's own folder (.claude) is the small dust ball at the centre, seen through the globe, with a glowing nucleus. Fine curved strands burst from it to every file and folder, warm near the nucleus and blue at the tip; the brightest go to files Claude has edited or created (from Claude Code's logs: only which files, nothing else). Light travels along them while the spin is on, and strands near your cursor bend aside. Point at a file to see how often Claude edited it. In the web view Claude's lines start at the .claude dot.
      health
      Possible problems: unused functions or CSS, ids that don't exist. Code that builds names at runtime can use things Atlas can't see, so check before deleting.

      Keyboard

      / search · Esc clear the selection · on the map: arrow keys turn, + − zoom, 0 fit · S spin on/off · V globe / web · ? this help

      Turning the globe

      Drag or use the arrow keys to turn it: it always turns around its own centre. Shift + drag or Shift + arrows slide it across the screen. The half of the grid facing you is brighter, and nearer dust is drawn bigger. Selecting something turns the globe until it faces you.
