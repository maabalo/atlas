    Reading the map

    Each shape is a piece of the project; each line is a link between two pieces. Click a shape (or search) to see exactly what uses it and what it uses.

    ■ square
    A file
    ● circle
    A function. Bigger = more connected (a "hub": change it carefully)
    ◆ diamond
    A class (Python)
    ▲ triangle
    An HTML id (#name)
    ○ ring
    A CSS class (.name)
    certain / inferred
    Certain links are written in the code. Inferred links were matched by name, so they're likely but not guaranteed.
    health
    Possible problems: unused functions or CSS, ids that don't exist. Code that builds names at runtime can use things Atlas can't see, so check before deleting.
