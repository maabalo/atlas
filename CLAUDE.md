# Atlas — notes for Claude

Read this first when working here. Update it whenever the process, a decision or a rule changes (what changed goes in CHANGELOG.md).

## What it is
- A map of a project: every folder, file and piece of code (functions, classes, HTML ids, CSS classes) as dust on a 3D globe with a 100 × 100 grid, plus health checks (unused code, missing ids).
- Repo: github.com/maabalo/atlas (**public**, MIT). Track: **Small tool** (no accounts or stored data).

## Stack and structure
- Python standard library only (no dependencies): `atlas.py` (CLI: build, uses, deps, explain, path, hubs, communities, check), `atlas_scan.py`, `atlas_graph.py`, `atlas_export.py`, `atlas_mcp.py` (MCP server for Claude Code, already registered as `atlas`).
- Viewer: `viewer/index.html`, `viewer/app.js`, `viewer/style.css`, embedded into each `graph.html` at build time (rebuild a map to see viewer changes). The globe layout is `layoutGlobe()` (placed once, in path order); drawing is section 06 (`makeGrid`/`drawGrid`, `makeStars`/`drawStars`, `drawDust`, `drawNames`).
- Mac app: `atlas_app.py` + `packaging/build_app.sh` → `dist/Atlas.app` (gitignored). Double-click rebuilds the combined Project map.

## Run, test, build
- Tests: `python3 -m unittest discover tests` (keep `tests/fixture`) and `node --test tests/core.test.js` (viewer/core.js).
- Viewer lint: run eslint/stylelint/prettier/html-validate in a temporary copy, then delete it.
- Build a map: `python3 atlas.py build <folder> [more folders] --name NAME --out DIR`.
- Rebuild the app after viewer changes: `sh packaging/build_app.sh`.
- `maps/` is gitignored on purpose: maps can contain names from private projects. Never commit them.
- **Push only when the user says so.**

## Rules and decisions (don't undo without asking)
- **Globe design (user's request, 2026-11-12):** a globe with a 100 × 100 grid (faint lines, the near half brighter); folders, files and code parts are **tiny dust scattered off the grid** (placed on evenly spread spots, `evenSpots`, then drifted by `scattered`: folders/files barely, code more); **no link lines** (arcs were tried twice, the second time with moving lights; removed again at the user's request on 2026-11-13: links are only used to light up what's linked); selecting highlights linked dust; labels off at first.
- **One panel, on the right (user's request, 2026-11-13; the left pane was merged into it):** hidden at first; `numbersBtn` (panel icon, top right) and `/` toggle it via `toggleNumbers` / `togglePanel` (layout class `has-numbers`, 320px column). Order inside: search, folders, numbers, health. No left pane or `sidebarBtn` any more.
- **Folders (user's request): a folder tree in the panel under search (`buildTree`: **every folder closed until clicked**; clicking glides the globe to it).** No islands panel and no type/label/community/inferred switches: everything is always shown.
- **Numbers then health, below the folders** (user's request, 2026-11-13). No selected-item details, hubs or community lists there.
- **Placement (user's request): folders are surrounded by their files.** `layoutGlobe` gives each project's top folder a start spot (`spreadDirections`, biggest first); `surround` puts a folder's files on the nearest free spots around it, then gives each subfolder its own room just outside that ring (`moveAlong`, distance from `discRadius`/`treeSize`) and repeats; code goes on the nearest free spot to its file (`placeCode`). Check: on the Project map ~88% of files have their own folder as the nearest folder. Clicks pick the nearest speck within 8 px (`nearestSpeck`).
- **Smooth turning (user's request):** `goTo` and `fit` call `glideTo` (quaternion `slerp` of the turn + eased view, `GLIDE_TO_MS`); drags, zoom and keys stop it (`stopMove`). Don't add a CSS transition to `.node`: fading 3,000 specks during a glide dropped it to ~10 fps.
- **Smooth zoom (user's request):** `zoomBy` sets a target that `stepZoom` eases toward (`ZOOM_EASE`), anchored under the pointer; instant with reduced motion; `fit`/`goTo` stop it (`stopZoom`).
- **The globe always turns around its own centre** (no moving pivot): selecting turns it to face you (`faceToward`), Shift-drag slides the view (`panBy`).
- Maps include **every file** except junk (`.DS_Store`, `.pyc`, skipped and hidden folders) and **every folder**, joined by `contains` edges. `contains` is ignored by shortest paths, hubs and communities.
- Opens with every type shown; **slow auto spin (user's request, 2026-11-13):** `SPIN_SPEED` 0.01 rad/s for the globe, `ORBIT_SPEED` 0.05 rad/s for the moon, repainted at `MOTION_FPS` 20 by `animateSpin`; paused while dragging or gliding; `spinBtn` / S switches it off (saved as `atlas-spin`, off at first with reduced motion). An earlier full-speed spin heated the MacBook Air, so keep it at 20 repaints and nothing when off; the galaxy, the navy redesign and the 2D/3D switch are gone.
- **Canvas, not SVG (2026-11-13, from the user's "Atlas Globe" prompt):** section 06 paints stars, grid, dust, rings and names on one `<canvas>` (`drawMap`, `drawSoon`), from flat arrays in `paint` (typed arrays, dust batched by brightness × colour, pixel ratio up to 2 for Retina; grid: `GRID_STEPS` 120/90 pieces, `GRID_LINE_PX` 0.5, meridians stop `POLE_GAP` 8° short of the poles, user's "finer, smoother" request). **Draw only on change**, except the slow spin (see below). No twinkle. The user's Mac heats up with nonstop full-speed drawing. Resizing the canvas wipes it, so `sizeCanvas` only resizes when the size really changes.
- **Dust colour = language, in soft pastels (user's request, 2026-11-13; mint before that)** (`LANG_COLORS`, `LANG_ALIASES`, folders near-white mint `FOLDER_COLOR`), with a legend (`renderLegend`); hover ring + tooltip (`showHover`, `hoverFacts`, text only via `el()`); selection link stays `#star=<id>`.
- **Moon / satellite (user's request, 2026-11-13: all of `~/.claude`, slow orbit; speed set to 0.05 rad/s later):** `atlas.py build --satellite F` merges F and sets `meta.satellite`; `atlas_app.SATELLITE` = `~/.claude` for the combined Project map only. Viewer: `isMoon`, `layoutGroup` per sphere, moon positions kept around its own centre (`MOON_SIZE`), `moonCentre()` on an orbit round the globe's equator tilted `ORBIT_TILT` (it starts on the right: `orbitStartAngle`; the old view-plane orbit slid across the globe and looked off), drawn behind or in front by depth (`drawGrid`/`drawDust` take a part, `coverWithGlobe` hides what's behind), `CAMERA_DISTANCE` 5 so the moon isn't stretched near the edges, `updateWorld()`/`paint.world`/`worldPoint()` for everything that needs real positions; the orbit only advances in `animateSpin`. Privacy: the map holds `.claude` file names (conversation ids too) but no note/conversation text; maps live outside the repo. `.claude` (~5,100 items) is bigger than all projects together.
